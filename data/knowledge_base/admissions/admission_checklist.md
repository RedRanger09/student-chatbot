# Admission Checklist for New Applicants

## 📚 Academic Documents
- [ ] Official transcripts from all previous institutions
- [ ] Degree certificates/diplomas (if applicable)
- [ ] Course descriptions for relevant coursework
- [ ] Proof of academic qualifications (e.g., GRE, TOEFL, etc.)

## 🎓 Identity Documents
- [ ] Passport copies (valid for at least 6 months)
- [ ] Birth certificate with apostille seal
- [ ] Government-issued ID (e.g., driver's license)
- [ ] Visa/Residence permit (for international applicants)

## 📷 Photographs
- [ ] Recent passport-sized photo (3.5cm x 4.5cm)
- [ ] White background, front-facing, no accessories
- [ ] Printed on high-quality matte paper

## 💰 Financial Documents
- [ ] Bank statements showing sufficient funds
- [ ] Scholarship/loan proofs (if applicable)
- [ ] Affidavit of financial support
- [ ] Proof of payment for application fees

## 🌍 International Student Requirements
- [ ] Visa documentation and travel itinerary
- [ ] Language proficiency test scores (IELTS, TOEFL)
- [ ] Health insurance coverage proof
- [ ] Immigration status documents

## ✅ Submission Checklist
1. Verify all documents are in English or with official translations
2. Ensure digital copies meet file size limits (≤5MB per document)
3. Confirm submission format requirements (PDF/Acrobat, JPG)
4. Double-check application deadlines
5. Review formatting guidelines for each document type

## 🚫 Before Submission
- [ ] Check for missing pages or blurred images
- [ ] Validate contact information accuracy
- [ ] Confirm payment receipt for processing fees
- [ ] Review program-specific requirements
- [ ] Save original documents as backups

## 📅 After Submission
- [ ] Track application status via portal
- [ ] Keep copies of all submitted materials
- [ ] Monitor email for official confirmation
- [ ] Prepare for possible document verification requests
- [ ] Stay updated on admission decisions timeline

## 🔍 Verification Checklist
- [ ] Authenticity verification of academic credentials
- [ ] Cross-check passport details with application form
- [ ] Confirm financial documents match declared amounts
- [ ] Validate visa status compliance
- [ ] Ensure health insurance coverage meets institutional requirements

## 🚨 Frequently Forgotten Items
- Notarized copies of all original documents
- Official translations with translation certifications
- Proof of immunization records (for health clearance)
- Additional letters of recommendation
- Program-specific supplements (e.g., portfolio, audition)

## ❓ Frequently Asked Questions

1. Can I submit documents in formats other than PDF?
   - Only PDF/Acrobat files are accepted for digital submissions

2. What if my documents are not in English?
   - Official translations with certified seals are required

3. How long does verification take?
   - Typically 4-6 weeks, but can vary by country

4. Can I apply without financial proof?
   - Partial applications may be accepted but require clarification

5. What if my passport is expired?
   - Must provide valid passport and visa documentation

6. Are there document size restrictions?
   - Maximum 5MB per file for digital submissions

7. Can I request extensions for submission deadlines?
   - Only in cases of documented emergencies

8. What happens if documents are missing?
   - Application may be delayed or rejected

9. How to prove English proficiency?
   - Acceptable tests: IELTS (6.5+), TOEFL (90+), PTE (65+)

10. Can I submit handwritten notes?
    - Only for specific forms; digital submissions required for documents

11. What if my visa is not yet approved?
    - Submit visa application confirmation instead

12. Are there special requirements for mature students?
    - Yes - include additional letters of experience

13. How to prove financial support?
    - Bank statements showing ≥$20k available funds

14. Can I apply without a passport?
    - No - valid passport is mandatory for international applicants

15. What if my documents are in a different currency?
    - Convert to USD using official exchange rates

16. How to handle missing pages in transcripts?
    - Submit explanation letter with academic supervisor's signature

17. Can I request document re-submission?
    - Yes, but must be done within 30 days of initial submission

18. What if my application is rejected?
    - Appeal within 45 days using official appeal form

19. Are there additional requirements for STEM programs?
    - Yes - include proof of relevant coursework and projects

20. Can I submit documents after the deadline?
    - Only with written permission from admissions office
