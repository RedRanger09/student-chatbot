# Campus Wi-Fi Guide

## Overview
The [University Name] campus wireless network provides high-speed internet access across all academic buildings, residence halls, and public spaces. This guide explains how students can register devices, authenticate connections, and use the network responsibly while adhering to institutional policies.

Key features include:
- 24/7 availability in designated coverage areas
- Multi-device support with connection limits
- Secure WPA3 encryption for data protection
- Guest access options for visitors
- Real-time network monitoring tools

Eligibility requirements apply to all students, faculty, and staff. Non-compliance with network policies may result in service suspension or account termination.

## Registration
### Device Requirements
Supported devices include:
- Windows 10/11 laptops
- macOS 10.14+
- Android 8.0+
- iOS 12+
- Chromebook (with Google Workspace for Education)
- Linux distributions with network manager

### Registration Process
1. Visit the IT Help Desk portal at [https://it.university.edu](https://it.university.edu)
2. Create a student account using your university ID number
3. Verify identity through email confirmation
4. Download the Wi-Fi registration certificate (PDF)
5. Install certificate on all devices

### Network Configuration
After registration, connect to:
- **SSID**: `University-WiFi`
- **Authentication**: WPA3-Enterprise (PEAP TLS)
- **IP Assignment**: DHCP automatic

## Login
### Credentials
Use your official university credentials:
- Username: Your student ID number
- Password: Your campus network password (change every 90 days)

### Login Process
1. Open a web browser and navigate to any website
2. A login prompt will appear automatically
3. Enter your username and password
4. Accept the Terms of Service agreement
5. Complete multi-factor authentication (MFA) via the U2F security key

### Password Policies
- Minimum 12 characters with special symbols
- No reuse of previous 5 passwords
- Automatic expiration every 90 days
- Lockout after 5 failed attempts

## Usage Policy
### Fair Usage Guidelines
- Monthly data cap: 3 TB (approximately 40 hours of streaming)
- Bandwidth prioritization for academic research
- Excess usage may result in temporary speed throttling
- Network performance is guaranteed during official university events

### Acceptable Use
Students are expected to:
- Use the network for educational purposes
- Avoid peer-to-peer file sharing without authorization
- Comply with all data privacy regulations
- Report suspicious activity immediately

### Device Limits
- Maximum 5 devices per student account
- Each device requires individual registration
- Simultaneous connections limited to 3 active sessions
- Temporary exemptions available for special circumstances

## Troubleshooting
### Common Issues
1. **Connection Failure**
   - Verify correct SSID selection
   - Ensure certificate is properly installed
   - Check for IP address conflicts
   - Restart router and device

2. **Slow Speeds**
   - Move closer to access points
   - Avoid using during peak hours (8 AM - 2 PM)
   - Clear browser cache and cookies
   - Use wired connection for high-bandwidth tasks

3. **Authentication Errors**
   - Confirm password is correct
   - Reset credentials through IT Help Desk
   - Verify certificate installation
   - Check for firewall/security software interference

4. **Guest Access Issues**
   - Guest devices must be registered separately
   - Temporary access limited to 2 hours
   - No data caps apply to guest connections
   - Requires valid visitor ID verification

### Network Outages
In the event of a service disruption:
1. Check official social media channels
2. Visit [https://status.university.edu](https://status.university.edu) for updates
3. Contact IT Help Desk for priority assistance
4. Use wired connections in academic buildings
