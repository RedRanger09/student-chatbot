# Transcript Request Guide

## Overview  
An academic transcript is an official document that summarizes a student's educational achievements, including coursework, grades, and degree completion status. It serves as proof of academic performance and is required for graduate admissions, employment verification, and other formal purposes. This guide outlines the process for requesting official and unofficial transcripts from [University Name], along with key policies and frequently asked questions.

## Eligibility  
Students, alumni, and authorized third parties (e.g., employers, educational institutions) may request transcripts. Third-party requests require a signed authorization form and valid identification from the student.  

### Student Requests  
- Current students: Request transcripts for enrollment verification or degree completion.  
- Alumni: Access transcripts for career development or further education.  

### Third-Party Requests  
- Must provide:  
  - Student’s full name and ID number  
  - Relationship to the student (e.g., employer, educational institution)  
  - Signed authorization form  
  - Valid photo ID of the student  

## Request Process
### Unofficial Transcript
- Available for personal use or submission to non-academic institutions.  
- Includes grade details but lacks the official seal and watermark.  
- Downloadable via [University Portal](https://portal.university.edu) (no shipping required).  

### Online Request
1. Log in to [University Portal](https://portal.university.edu) with your credentials.  
2. Navigate to "Academic Services" > "Transcript Requests."  
3. Select "Request Official Transcript" or "Request Unofficial Transcript."  
4. Choose delivery method:  
   - **Digital**: Email via secure portal (instant delivery).  
   - **Physical**: Mail to provided address (processing time applies).  
5. Review and submit request.  

### Offline Request  
1. Complete the [Transcript Request Form](https://forms.university.edu/transcript) and mail it to:  
   ```
   Academic Records Office  
   University Name  
   123 Education Drive  
   City, State, ZIP Code  
   ```  
2. Include:  
   - Completed form with payment (see fees below)  
   - Valid photo ID of the student  

## Processing
### Processing Time
- **Digital Requests**: Instant approval (within 1 business day).  
- **Physical Requests**: 5–7 business days for processing; additional time for mail delivery.  

### Fees
- **Official Transcript**: $25 per request (includes one copy).  
- **Additional Copies**: $10 each.  
- **Digital Delivery**: Free (no extra charge).  
- **International Mailing**: $30 surcharge.  

### Multiple Copies
